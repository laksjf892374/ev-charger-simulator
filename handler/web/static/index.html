A CPO runs chargers. An eMSP is the app drivers use — one account that works across many CPOs, like a travel site on top of many airlines.

Testing against a real CPO takes a partner sandbox and physical chargers. This is a CPO you control: run the everyday flow, make chargers as reliable as real ones, or make one fail.
